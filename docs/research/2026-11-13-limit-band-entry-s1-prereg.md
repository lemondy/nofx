# 限价入场按带宽方程定挂单深度：离线 S1 预注册（C1，2026-11-13）

## 0. 背景与问题

- **来源。** `2026-11-13-microstructure-ou-band-assessment.md` 的候选 C1。论文（arXiv 2608.00885）的结论是：当价格偏离超过成本、达到带宽 θ*(θ*−φ)=s_G² 时才交易，偏离一覆盖成本就交易的规则收益为零。评估时不建议启动 C1，用户 2026-11-13 明确要求启动。
- **问题。** LLM 加密交易员现在全部市价入场（所有在用策略 `limit_entry_enabled=0`）。如果改成在入场价外侧 θ* 处挂限价单，30 分钟未成交再转市价，每笔交易是否更好？
- **与已有研究的区别。**
  - 10-15 的决策重放（`entry-exit-replay`）比较过市价与 ATR 尺度的限价入场，结论是约持平。
  - 10-19 的回抽确认（`range-breakdown-short`）挂单深度为 0.5/1.0×ATR，不显著。
  - 本次的挂单深度是成本尺度（约 8–15bp，由带宽方程决定），未成交时转市价而不是放弃，因此样本里的交易全部保留，属于“同一批入场、只改执行”的 C 类比较。
- **框架位置。** 增量评估 S1，类型 C（执行/出场规则），track 为 `crypto_llm`，**K=6**（之前 5 个 S1）。strong 门槛 z_K = Φ⁻¹(1 − 0.025/6) = **2.638**，screen_pass 门槛 z ≥ 1。
- **先验：低。** 按论文公式，nofx 的 γ = φ/s_G 远大于 1，预期收益接近零；限价单还存在逆向选择（价格继续朝不利方向走时才成交，价格朝有利方向跑掉时则转为更差的市价）。

### 收益来源声明

- **付钱方：** 吃单方。挂单成交时，nofx 不再付价差和吃单费（吃单 5bp 对挂单 2bp），由主动成交的对手方付这部分；再加上短时偏离回归带来的更优价格。
- **为何持续：** 交易所的挂单/吃单费率差，以及急躁的流动性需求，都是结构性的。
- **侵蚀因素与公开年限：** 逆向选择会侵蚀它：限价单成交往往是因为信息流朝不利方向走。做市文献（Avellaneda-Stoikov 2008 起）和执行文献公开已有 20 年以上。
- **容量与成本：** nofx 单笔名义价值很小，不影响盘口。单笔最多节省约 θ* + 3bp 费差，相对初始止损距离（约 1–3%），量级约为 0.01–0.05R。

- **下载。** 每笔交易下载 Binance U 本位 1m K 线，区间为 [入场分钟 − 1440 分钟, 入场分钟 + 31 分钟]。

- **价格核对。** 入场价落在入场分钟 K 线 [low×0.998, high×1.002] 内的比例必须 ≥ 95%，否则 invalid。

## 3. 反事实模型

**记号：**

| 符号 | 含义 |
|---|---|
| s | 方向，多 +1、空 −1 |
| E | 实际入场价 |
| Te | 入场时间；Te_min 为其所在分钟的开盘时间 |
| X、Tx | 实际出场价、出场时间 |
| SL0 | 初始止损 |
| R0 | \|E − SL0\| |

1. **s_G（Roll 估计）。** 取开盘时间在 [Te_min − 1440 分钟, Te_min) 内的 1m 收盘价，只对相邻两分钟都存在的对计算对数收益 r。cov1 为 r 的滞后 1 阶自协方差（去均值，除以对数），s_G = √max(0, −cov1)。
   - 依据：论文的 gap 是 OU 过程，回归速率为秒级；在 1m 间隔上，相邻收益的协方差约等于 −s_G²。
2. **φ = 0.0008**，即研究口径的吃单 5bp 加滑点 3bp。
3. **θ\* = ½(φ + √(φ² + 4·s_G²))**（论文式 3.7，相对价格单位）。限价 L = E·(1 − s·θ\*)。
   - 若 L 已达到或越过止损（s·(L − SL0) ≤ 0），候选与基线相同，Δ = 0，并计数。
4. **成交判定。** 从入场分钟的下一根开始，检查开盘时间在 (Te_min, Te_min + 30 分钟] 内、且收盘时间（开盘 + 60s）≤ Tx 的 K 线，最多 30 根。
   - 多头：取第一根 low < L 的 K 线（**严格穿价**）；空头：取第一根 high > L 的 K 线。
   - 成交价为 L，挂单费 2bp（0.0002）。
   - 入场分钟本身不检查，这是保守处理。
5. **未成交，转市价。** 30 根窗口完整且都没有成交时，在第 30 根的收盘价 c 处市价入场，成交价为 c·(1 + s·0.0003)（3bp 不利滑点），吃单费 5bp。
6. **未成交，且窗口被出场截断。** 即 Tx 早于窗口结束：候选没有入场，净 R = 0，计为 missed。
7. **出场。** 两臂都在实际 X 平仓，吃单费 5bp，数量相同（按基线的单位名义）。
   - 依据：候选的持仓区间是基线 [Te, Tx] 的子区间。止损和止盈是同一组绝对价位，基线在 Tx 的出场对候选同样适用。
   - 这是本模型的核心假设，局限见第 7 节。

**净 R（以 R0 为单位，含全部手续费）：**

- 基线：B = [s·(X − E) − 0.0005·E − 0.0005·X] / R0
- 候选，以价格 P、费率 f 入场：C = [s·(X − P) − f·P − 0.0005·X] / R0
- 候选，missed：C = 0

配对差：Δ_i = C_i − B_i。

**撮合必须走 Backtrader（`scripts/backtest`）。** 另写一个纯算术的参考实现，单测要求两者逐笔差 ≤ 1e-9 R。

## 4. 机制校验（在计算 Δ 之前完成）

- Backtrader 与算术参考逐笔一致（≤ 1e-9 R）；不一致则 invalid。
- 有效交易 < 100，判 invalid。
- 只报告、不作门槛：s_G 的分布（中位数，单位 bp）、cov1 ≥ 0 的比例、θ\* 与 γ = φ/s_G 的分布。

## 5. 判定（类型 C，K=6，z_K = 2.638）

**主统计量。** Δ 的均值，按入场 UTC 周（周一开始）聚类，使用 `incremental_filter.weekly_statistics`，z = 均值 / SE。

**两半。** 按入场时间排序，切成笔数相等的前后两半，分别算 Δ 均值。

**missed 处理。** 若 missed 笔数 > 5% 且全体 Δ > 0，但剔除 missed 后的 Δ ≤ 0，判 `fewer_trades`。

| 判定 | 条件 |
|---|---|
| invalid | 第 1、2、4 节的校验未通过 |
| fewer_trades | 见上一条 |
| strong | z ≥ 2.638 且两半 Δ 均 > 0 |
| screen_pass | z ≥ 1 且两半 Δ 均 > 0 |
| fail | 其他情况 |

**后果：**

- **fail / fewer_trades：** 关闭 C1。成本尺度的限价入场不接入，没有新证据不再提。
- **screen_pass / strong：** 向用户提出 S2 线上配对。S2 需要新增代码：θ\* 挂单深度模式，以及“30 分钟超时转市价”。现有限价逻辑超时只撤单，只在价格已越过锚点时才转市价。是否实施由用户决定。

## 6. 仅描述，不参与判定

- 成交率、转市价率、missed 率；Δ 按“限价成交 / 转市价 / missed”分组的均值。
- **逆向选择：** 限价成交组与未成交组的基线 B 均值之差。
- 按交易员、多空分组的 Δ。
- Δ 按日聚类的 z。
- **敏感性：**
  1. 触价即成交（low ≤ L）；
  2. 固定挂单深度 4bp、15bp、30bp（其余规则不变）；
  3. 不转市价（未成交即放弃，计 0），同时报告剔除未成交后的 Δ；
  4. 转市价不加滑点；
  5. 挂单费按吃单 5bp 计。

## 7. 局限（预先承认）

- 1m K 线的最低/最高价是成交价，不是中间价；严格穿价也不能保证队列排到。敏感性 1 给出乐观上限。
- 模拟盘的 E 可能不含真实滑点，基线因此被高估，对候选不利。实盘只占 64 笔。
- LLM 后续决策（保本档 0.75R、减仓 1.2R、AI 主动平仓）按 R 计算时依赖入场价。模型把出场当作外生，没有反映入场价变化带来的影响。
- Roll 估计在 1m 收盘价上测到的主要是买卖价反弹，不是论文的中间价 gap。论文的 G 在 nofx 无法观测（评估第 5.1 节），本检验是可执行的近似。
- 样本与 early-trim、Kronos 研究部分重叠，基线收益已经看过；但候选执行方式的结果此前从未计算过。
- 不模拟资金费、强平，以及挂单对市场的影响。
