## 2. 核心机制与适用条件

下表“类型”一栏的含义：

- **主张**：作者的观点；
- **证据**：所引论文报告的数字；
- **推断**：本文作者（nofx 这边）的推断。

| 编号 | 机制或结论 | 类型 | 出处 | 适用条件 |
|---|---|---|---|---|
| M1 | **复杂模型的优点。** 模型错设时，参数多于样本（P > T）的岭回归或随机特征模型，样本外 R² 和择时夏普都随复杂度上升。前提是收缩力度要选对：“permanent ascent” | 理论加校准 | p.17–25 | 预测能力分散在许多信号上；必须有收缩 |
| M2 | **复杂度楔子。** 可实现的夏普比真实模型低约一个数量级。Da 等（2022）在美股中算出：不可实现的夏普约 2.5，可实现的约 0.5（扣成本前） | 证据 | p.26–27，p.101 | 用来校准预期 |
| M3 | **R² 或 IC 不能代表经济价值。** 应当用策略夏普等经济指标来评价模型 | 主张加证据 | p.66 | 通用 |
| M4 | **惩罚线性模型。** 1000 个预测变量用 OLS，R² 为 −35%，加上弹性网就转正，多空夏普 1.33。He 等（2022a）发现，弹性网的集成能跟上最优模型的漂移 | 证据 | p.40–42 | 美股月频 |
| M5 | **非线性模型更好。** 神经网络和树模型优于线性模型，Gu 等（2020b）：月度 R² 约 0.4%。神经网络多空组合的 FF6 α 为 t≈5（市值加权） | 证据 | p.64–66 | 美股月频、94 个特征 |
| M6 | **多重检验用来选因子会过于保守。** 用 FDR 或 Bonferroni 逐个挑因子，得到的组合过于保守；Jensen 等（2021）的贝叶斯层级收缩组合明显更好 | 证据 | p.102–104 | 因子数量多时 |
| M7 | **MSRR 与参数化组合。** 把 1 对因子管理组合 F_t = S'_{t−1}R_t 回归，系数 β ∝ (Cov(F)+zI)⁻¹E(F)，也就是直接以夏普为目标、带岭收缩的组合权重。线性 MSRR 夏普 1.8，神经网络版 2.5（Simon 等 2022） | 方法加证据 | p.112–118 | 能自然地加入 ℓ1 杠杆约束和 ℓ2 成本惩罚 |
| M8 | **考虑交易成本的组合。** 最优组合是部分调整：w_t ≈ m·w_{t−1} + (1−m)·A_t，其中目标组合 A_t 是未来各期 Markowitz 组合的平滑。成本越高，m 越大。这种一步法的扣成本表现优于“先预测再平滑”的两步法（Jensen 等 2022） | 理论加证据 | p.126–130 | 换手率高的策略 |
| M9 | **ML 的盈利主要来自小盘、低流动性股票和短命信号。** 扣掉交易成本后，很多模型不再赚钱。补读发现两点修正：Gu 等的神经网络在大盘股上的 R² 反而更高（0.70%），但市值加权的多空夏普只有约 1.2，等权约 2.1–2.4，说明盈利集中在小盘股；Avramov 等（2022a）认为扣成本后仍有收益，主要来自多头 | 主张加证据 | p.61–63，p.126 | 我们交易的 bStock 是大盘股 |
| M10 | **另类数据。** 用 LLM 把新闻转成嵌入向量，再接一个监督模型，效果优于词袋法（Jiang 等 2023）。CNN 读 K 线图做周频多空，等权夏普 7.2、市值加权 1.7；其中一部分可以用“收盘价接近近期高低区间底部，下周上涨”这个简单信号近似（Jiang 等 2022） | 证据 | p.71–78 | 需要带时间戳的历史新闻；美股周频 |
| M11 | **实验设计。** 训练、验证、测试按时间顺序切分，中间留隔离期，并递归滚动重训。R² 以零预测为基准 | 方法 | p.32–37，p.65 | 通用 |
| M13 | **主成分组合（PPA）。** 用所有资产的信号去预测所有资产的收益，得到“预测矩阵”Π = E(R_{t+1}S_t′)。对 Π 做 SVD，得到最可被预测的组合；其中反对称部分对应纯 alpha 组合。在 25 个 FF 组合加时间序列动量上，样本外夏普和 alpha 都显著（Kelly 等 2020a） | 方法加证据 | p.51–53 | 适合资产之间存在领先滞后关系的市场 |
| M14 | **IPCA 与条件自编码器。** 用可观测特征决定随时间变化的 β。参数比可观测因子模型少约 95%，预测 R² 更高；样本内外都比 PCA 稳健 | 证据 | p.89–95 | 风险模型和风格暴露 |
| M15 | **因子选择不稳定。** 换一个交叉验证的随机种子，lasso 选出的因子就差别很大。Feng 等（2020）的递归检验发现，120 多个因子里只有 17 个有用 | 证据 | p.86–88 | 支持 M6 “收缩优于筛选” |
| M12 | **强化学习。** 对价格接受者帮助有限，主要用于做市和执行 | 主张 | p.130–131 | 我们是价格接受者，不需要 |

## 3. 与 nofx 的重复、互补和冲突

**已经实现或已经检验过（重复）：**

- **M3 经济指标优先：** 增量评估框架已经用配对的扣成本净收益 Δ 作主指标，不再只看 IC（`docs/architecture/INCREMENTAL_EVAL_DESIGN_2026-11-03.md`）。
- **M11 时间切分：** 挖掘器使用固定的训练、验证、留出切分，并做前向检验。
- **用 ML 过滤 LLM 信号：** 已经做过 meta-labeling（研究记录 `meta-labeling`）。在 420 个信号上用 logit、ridge、HGB，样本外 AUC 只有 0.43–0.54，结论是无可部署过滤器。
- **宽池因子合成：** 已经做过（`wide-pool-ensemble`）。40 个因子按 ICIR 贪心选出，权重向等权收缩，结果 S1 fail，Δ −0.125%/日。

**互补（nofx 还没有、可以借鉴）：**

- **M6 收缩取代筛选：** 挖掘器的准入是逐个因子做 Bonferroni 检验，累计 K 约 1.5 万，t 门槛约 4.65。这正是综述批评的“多重检验当选择器”，会过于保守。综述的替代做法是对所有候选做联合收缩（岭回归或贝叶斯层级模型）。
- **M7 直接以夏普为目标定权重：** 线上 fq_crypto 的做法是把因子百分位等权合成，再做五分位多空。多次研究都发现同一个问题：IC 为正、多空却亏钱，亏在空头腿（`ensemble-forward`、`style-neutral-factors`）。MSRR 直接对“各因子、各腿的管理组合收益”估计夏普最优权重，有机会自动降低空头腿的权重。现有研究都还没有在“组合权重”这一层做过优化。
- **M8 部分调整：** 线上 fq_crypto 每 3 日调仓，用 10% 的调仓阈值减少交易。alpha101 研究的结论是“加密币有 IC，但被换手吃掉”。部分调整是有理论最优解的降换手方法，nofx 还没有试过。

**冲突，或者不适用：**

- **M1、M5 复杂模型：** 前提是预测能力分散在许多信号上，样本也够大（美股月频，每月数千只股票）。我们的加密截面约 60 只币，日频数据约 4 年，可用的“有效”因子本质上只是低波动、低贝塔这一种风格（`style-neutral-factors`）。复杂模型修不好空头腿的问题。
- **M9 收益来自小盘和低流动性：** 恰好解释了 nofx 在美股上的一系列失败。bStock 是 90 只大盘股，而 ML 的收益主要来自小盘股。这进一步支持“美股因子挖掘已暂停”的决定。
- **M10 文本与图像：** 文本这条路缺少带时间戳的历史新闻数据，属于数据缺口。图像那条“收盘价接近近期高低区间底部，下周上涨”是美股周频、短区间的反转现象。
  - nofx 在美股测过的 52 周区间位置是另一回事：range_pos 的 20 日 IC 为 +0.073，表现为动量延续，按区间做反转排序反而明显更差（研究记录 `us-range-reversal`）。两者周期不同，不能直接对照。
  - 短区间的位置这类形态，挖掘器的 OHLC 表达式已经能表示。
- **M12 强化学习：** 不需要。

**独立策略价值：** 无。这是一篇综述，不提供可以直接交易的规则。

**相对当前基线的增量价值：** 集中在 fq_crypto 的组合构建层（M7、M8）和挖掘器的准入方式（M6）。LLM 交易路径能借鉴的只有 M3 这类方法论。

## 4. 可检验假设（按优先级排序，最多三个）

### H1：用岭收缩的 MSRR 组合权重替换“等权打分加五分位多空”（fq_crypto）

- **机制：** 把每个因子的多头腿和空头腿各自拆成一个管理组合，在训练段估计带岭收缩的夏普最优权重，β ∝ (Cov(F)+zI)⁻¹E(F)。这样模型可以把空头腿（高波动币）的权重压低，或者让它只承担对冲作用，同时考虑各因子之间的相关性。
- **改动：** 只替换组合构建这一步，因子集合、币池、调仓周期、费用和资金费都与线上相同。
  - 因子集合：线上 h=3 ensemble 的 7 个因子。
  - 币池：top60，排除上市不满 90 日的币和 7 日涨幅前 10% 的空头。
  - 调仓周期：3 日。
- **防止只学到大盘贝塔：** 把 BTC 收益作为额外一列放进 F，或者先把各腿对 BTC 做 β 对冲。这一选择要在预注册里写死。
- **约束：** 总杠杆 ≤ 1，单币权重上限 0.10，与现行规则一致。
- **数据：** 现有的 `data/factor_mining/crypto` 面板，加上冻结的 ensemble 因子定义，不需要新数据。
- **主指标：** 与线上规则配对的日均扣成本净收益 Δ，用周聚类 SE，分别在验证段和前向段计算。
- **辅助指标：** 夏普、最大回撤、换手率，以及空头腿的盈亏贡献。
- **失败条件（预注册时写死）：**
  - 合并 Δ 的 z < 1.65，或者验证段与前向段的 Δ 符号不一致；
  - 或者权重主要落在 BTC 那一列上（说明学到的只是贝塔）；
  - 收缩参数 z 只在训练段内用时间序列交叉验证选，选的网格事先固定。
- **成本：** 中等。可以复用 `style_neutral_study` 的 Backtrader 两腿框架，账本 K 记在 fq_crypto（当前 K=3，本次 +1）。
- **风险和冲突：**
  - 验证段和前向段的数据都已经看过多次，所以 S1 只能算“筛选”。
  - 管理组合只有 14–15 列，样本约 400 个 3 日期，估计误差不小，好在岭收缩可以缓解。

### H2：用部分调整取代“每 3 日全量调仓加 10% 阈值”（fq_crypto）

- **机制：** 按 Gârleanu-Pedersen（2013）和 Jensen 等（2022），令 w_t = m·w_{t−1} + (1−m)·A_t，A_t 取现行规则算出的目标权重。成本越高，m 越大，这样可以把交易成本摊到多个周期，只追随持续时间长的信号。
- **改动：** 信号和目标权重完全相同（等同于“同一批入场”），只改变向目标调仓的速度。
- **参数：** m 的网格事先固定为 {0, 0.33, 0.5, 0.67}，其中 m=0 就是现行规则；只在训练段选 m。
- **数据：** 同 H1。
- **指标：** 与现行规则配对的扣成本 Δ、换手率、跟踪误差。
- **失败条件：** 合并 Δ 的 z < 1.65，或者 Δ 只来自少数几天（周聚类后不显著）。
- **成本：** 低。
- **冲突：** 与 H1 不冲突，H1 通过后可以叠加。
- **先验较弱：** `fq-stop-tp` 等研究显示前向亏损主要是入场（信号）的问题，部分调整只能减少成本，不能制造收益。

### H3：挖掘器准入从“逐个因子 Bonferroni”改为“对候选池联合岭收缩”（离线对照）

- **机制：** 对应 M6 和 M1，用联合收缩代替逐个挑选。
- **改动：** 在训练段对 h=3 的全部训练期达标候选（约 3650 个，见 `wide-pool-ensemble`）的百分位，做截面岭回归或随机特征岭回归，预测 3 日收益；收缩参数 z 用训练段内的时间序列交叉验证选。再与线上 7 因子 ensemble 做配对对照，组合构建方式不变。
- **失败条件：** 同 H1。另外要求做风格中性化之后增量仍为正，否则说明它只是低波动风格的另一种写法。
- **成本：** 中高，要算 3650 列因子的面板，数据量大。
- **先验低：**
  - `style-neutral-factors` 显示，几十个准入因子的风格 R² 中位数为 0.54，联合收缩很可能只是更精细地复制了低波动风格。
  - 联合收缩也修不好空头腿的问题。
  - 建议只在 H1 通过后再做。

### 补充候选 H4：主成分组合（PPA，对应 M13）

- **机制：** 加密币之间可能有领先滞后关系，比如主流币领先山寨币。PPA 直接估计“所有币的信号 → 所有币的下一期收益”这个交叉预测矩阵，再取前几个奇异向量作为组合；其反对称部分对应纯 alpha。
- **与 nofx 的关系：** nofx 现有的因子都只用币自身的信号预测自己，还没有检验过跨币预测。
- **改动：** 在训练段，用加密日线面板估计 Π（信号取过去 3 日收益或 12-1 动量，事先固定一种），取前 3 个主 alpha 组合，与基线配对比较。
- **先验：** 偏低。日频上的领先滞后多半在一天之内就消失了，另外币池只有约 40 个，Π 的估计噪声很大。
- **建议：** 等 H1 有结果后再决定是否做。（H1 已于同日完成，结果是 fail，见 `docs/research/2026-11-07-fq-crypto-msrr-study.md`。）

**不提出的方向及原因：**

- LLM 新闻嵌入：缺少数据，而且信号层的 ML 过滤器已经失败过（AUC 约 0.5）。
- CNN 读 K 线图：训练成本高；它近似出的短区间形态，挖掘器的表达式已经能覆盖。
- SDF、GAN、强化学习：是研究工具，不是交易规则；我们是价格接受者。
- 美股方向：美股因子挖掘已于 2026-11-06 暂停；综述 M9 也支持这一决定。

## 6. 结论与建议

结论档位：**证据不足**。综述本身没有可以直接接入的内容，复杂模型那部分也不适合我们的数据规模。

可借鉴的有三点，按优先级：

1. **H1（MSRR 组合权重）：** 直接针对 fq_crypto 反复出现的“IC 为正但多空亏钱”。值得做 S1 离线验证。
2. **H2（部分调整）：** 实现成本低，只能降低交易成本。
