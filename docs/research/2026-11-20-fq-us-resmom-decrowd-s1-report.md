## 1. 工程与回测口径说明

1. **修复 NautilusTrader 大股票池节流缺陷**：在开发本实验期间发现 NautilusTrader 默认 `RiskEngineConfig` 限速 `100 orders/s`，当 S&P 500 D3 单次调仓需提交 `~200` 笔市价单时，第 101 笔及以后的订单会被静默拒绝。已在 `scripts/backtest/nt_engine.py` 统一配置 `RiskEngineConfig(bypass=True, max_order_submit_rate="100000/00:00:01", max_order_modify_rate="100000/00:00:01")`，并新增 `PortfolioEngineSession`（基于原生 `engine.reset()` + `engine.clear_strategies()` + `CarryFundingModule.reset()`），单测 `scripts/backtest/tests/test_nt_engine.py`（`18/18` 通过）验证大池 0 拒单与按位一致复现。
2. **安慰剂早停披露（Futility Early Stop）**：预注册计划在 D3（498 标的 × 14 年日线，约 335 万事件/次）上对 H1/H2 各运行 `200` 次完整 NautilusTrader 安慰剂回测。由于两者主门统计量已确定性锁定 `verdict = fail`（`H1 z = -0.045 < 1.0` 且 `half2 = -10.60 bps < 0`；`H2 z = -0.400 < 1.0` 且 `half1 = -1.10 bps < 0`），且单次 498 标的完整 NautilusTrader 回放耗时约 22s、受 16GB 本机内存并发限制，在各完成 **`n = 30`** 次完整 NautilusTrader 安慰剂后按无效早停规则结束（共 60 次完整 14 年 498 标的 NautilusTrader 模拟），并在 `data/evolution/ledger.jsonl` 如实披露 `placebo_n = 30`、`prereg_placebo_n = 200` 与 `placebo_note`。代码硬门禁保证了任何非确定性 `fail`（`z >= 1.0`）或潜在通过候选仍严格强制 `placebo_n >= 200`。

## 4. 机制归因与工程决策

1. **为什么 `H1`（残差动量）失败且在 D2 灾难性失效？**
   - **换手率与成本激增近 3 倍**：D3 手续费由 `\$10,819` 飙升至 `\$29,627`（成交笔数 `39,973 → 51,890`），原因是 252 日滚动回归残差的标准差标准化导致相邻调仓期排名跳变剧烈，扣除 10bp 手续费与融券费后吃光了所有波动率压缩收益。
   - **剔除真实 Beta 反而跑输随机置换 Beta（`0.0%` 安慰剂分位）**：D3 30 次随机打乱个股 SPY Beta 的安慰剂均值高达 `+6.35 bps/期`（而真实 `H1` 仅 `-0.87 bps/期`）；在现代科技主导的 D2 `bStock 90` 池中，真正驱动 12-1 动量超额收益的正是高 Beta 成长主线的趋势延续，剔除 SPY 回归项后直接导致 `-40.61%`（Sharpe `-0.691`）崩盘。
   - **仅在 2009 崩盘期有效，且已被 `B_volscale` 严格占优**：`H1` 在 D1 2009 崩盘期确实收窄了 MaxDD（`-35.75% → -13.74%`），但 `B_volscale` 以**更低手续费**（`\$3,624` vs `\$10,834`）捕获了大部分危机保护（D1 MaxDD `-21.22%`，`z = +1.436`），同时在 D3 取得唯一正收益（`+9.68%`）、在 D2 保持 `+124.06%` 与最高 Sharpe `0.960` / Calmar `0.878`。
2. **为什么 `H2`（相关性去拥挤加权）平庸无效？**
   - 在已应用 `1/σ` 与 10% 单票上限的组合上，60d 平均正相关惩罚仅把有效独立赌注 $N_{\text{eff}}$ 温和拉高 `+0.25`（D3 `3.35/3.67 → 3.62/3.90`，D2 `2.42/3.17 → 2.56/3.28`），却轻微拉高手续费并在 D3/D2/D1 三池均录得微弱负差（`-0.54` / `-1.16` / `-0.76 bps/期`），且安慰剂 `50.0%` 分位证实其与随机重排惩罚向量无统计差异。
3. **结论与下一步**：
   - `fq_us K=12`（`H1`）与 `K=13`（`H2`）均已诚实写入 `data/evolution/ledger.jsonl` 判 **`fail`**；**不修改** `scripts/factor_mining/quant_targets.py`。
   - **严格保留冻结的 `fq_us` S2 对照组**（`1025e717...` `B_base` vs `490f8b28...` `B_volscale`，`2026-12-01` 启动），本次独立 NautilusTrader 全量回放再次验证 `B_volscale` 是美股高 ROI 唯一胜出方案。
