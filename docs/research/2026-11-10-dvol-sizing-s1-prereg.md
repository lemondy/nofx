## 3. 波动预测（每个币种分别估计）

- **变量与样本外流程与 H1 完全相同**：第 2–3 节的 Parkinson HAR 分量、目标 Y_t（未来 7 日已实现方差）、对数 OLS、扩展窗口、每月重估（训练样本满足 t + 7 < 当月第一天）、训练从 2021-04-24 开始。直接复用 `scripts/backtest/dvol_vol_forecast_study.py` 的函数，不重写。
- **模型：**
  - B（HAR）：ln Y = a + b1 ln RV1 + b2 ln RV7 + b3 ln RV30；
  - C（HAR + DVOL）：B 加 c × ln IV。BTC、ETH 用各自的 DVOL；SOL、BNB、XRP、DOGE 都用 **BTC 的 DVOL**（IV_BTC）。
- **水平校准（B、C 相同）：** F_t = exp(ŷ_t + s²/2)，其中 s² = Σe² / (n − p)，为当月那次训练拟合的残差方差，n 为训练样本数，p 为参数个数（含截距）。σ̂_t = √F_t（年化）。
- **描述用的参照模型：**
  - T（滞后已实现波动）：σ̂_t = √RV30_t，相当于"拿过去 30 天波动直接当预测"，接近 fq 现行 1/σ 的口径；
  - U（不缩放）：k ≡ 1，即现行 LLM 交易员（vol_target 关闭、没有市场层缩放器）。

## 4. 缩放规则（交易规则本身，不用未来数据）

- **参照水平：** σ_ref,i,t 为币种 i 从 2021-04-24 到 t（含）全部有效 √RV30 的中位数（扩展窗口）。
- **缩放系数：** k_i,t = min(1, σ_ref,i,t / σ̂_i,t)。只减不加，k 在 (0, 1] 之间。B、C、T 各算一套，共用同一个 σ_ref。
- **生效：** 日 t 收盘（UTC 24:00）算出 k_i,t，作为 t+1 日持仓占权益的比例。日收益 r_i,t+1 = C_{t+1}/C_t − 1，缩放后 x_i,t = k_i,t × r_i,t+1。每日重设，不计成本（成本只作描述）。
- **评估日：** 预测日 t 落在 2023-01-01 至 2026-10-31，且 B、C、T 都有有效预测、r_{t+1} 可得。三个模型用同一组日期。

## 5. 评估载体与指标

**三个载体：**
- BTC：BTC 永续，用 BTC 的模型；
- ETH：ETH 永续，用 ETH 的模型；
- ALT4：SOL、BNB、XRP、DOGE 等权组合，每个币用自己的 k（模型 C 借用 BTC DVOL）。x_ALT,t = 四个 x_i,t 的平均，敞口 = 四个 k_i,t 的平均。只取四个币都有效的日子。

**敞口归一化（评估手段）：** 每个载体、每个模型，x̃_t = x_t ÷ 评估期内平均敞口。U 的平均敞口为 1。这样比较的是"同样的平均资金占用下"的风险。

**指标：**
1. **校准 L：** 每个币种的样本外 QLIKE = Y/F − ln(Y/F) − 1，按日平均，用第 3 节校准后的 F。
2. **日尾部 ES：** |x̃_t| 中最大的 ⌈0.025 n⌉ 个值的平均，越小越好。
3. **超额风险周损失：**
   - 从评估期第 1 个日期起，按评估日序列每 7 个连续日期切成不重叠的块，最后不足 7 天的块丢弃；
   - 每块 V_b = (365/7) × Σ x̃²（年化）；
   - 阈值 V* = 不缩放（U）在全部块上 V_b 的中位数，每个载体一个常数，B、C 共用；
   - 每块损失 ℓ_b = (max(0, ln(V_b / V*)))²，只惩罚风险超出"普通一周"的部分，这正是只减不加缩放的目的；
   - 配对差 d_b = ℓ_B,b − ℓ_C,b（为正表示 C 更好），t = mean(d) / (sd(d)/√n_blocks)，普通 t；
   - 两半：块数平分，奇数时前半取 ⌊n/2⌋，各自算 mean(d)。

## 6. 判定

每个载体 c 定义两个条件：
- **R1(c)：** 超额风险周损失的配对 t ≥ 2.0，且前后两半的 mean(d) 都 > 0。
- **R2(c)：** ES_C < ES_B，且 ES_C < ES_U（C 既要胜过 HAR 缩放，也要胜过不缩放）。

校准条件：
- **L_main：** BTC、ETH 各自 QLIKE_C < QLIKE_B；
- **L_alt：** 四个山寨币中至少 3 个 QLIKE_C < QLIKE_B。

| 判定 | 条件 |
|---|---|
| invalid | 第 2 节数据校验不过 |
| pass | L_main、L_alt 成立，且 BTC、ETH、ALT4 三个载体都满足 R1 和 R2 |
| weak | 不满足 pass，但 L_main 成立，且 BTC、ETH 都满足 R1 和 R2。DVOL 缩放只对 BTC、ETH 有效，借给山寨币不成立 |
| fail | 其他情况 |

**后果：**
- **pass：** 另写接入设计和在线配对（S2）预注册：LLM 交易员加市场层 DVOL 缩放器（需要接入 Deribit 公共接口），对照现行不缩放。不改现行配置。
- **weak：** 记录在案。LLM 交易员主要交易山寨币，仅 BTC、ETH 有效的接入价值有限，默认不接入，除非用户另行决定。
- **fail：** 不接入，记录在案，不调参重跑。

## 9. 已知局限

- DVOL 只覆盖 BTC、ETH；山寨币只能借用 BTC 的 DVOL，ALT4 只有 4 个大市值山寨币，LLM 交易员实际交易的多为小市值币，代表性有限。
- 日线粒度、每日重设，与线上"开仓时缩放 + 持仓期减仓"的执行方式不同。
- 评估期没有像 2022 年那样完整的熊市。
- 只减不加的缩放会降低平均敞口；归一化用到了评估期的平均敞口，是评估手段，不是可交易规则。
- 多重检验：主判定只有一组设定；T、未校准、方向夏普等只作描述，不得事后替换主判定。
