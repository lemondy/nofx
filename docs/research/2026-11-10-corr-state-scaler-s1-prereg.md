# 币种间相关性状态用于山寨币组合仓位缩放：S1 预注册（2026-11-10）

本文件在编写评估代码、看到本研究任何结果之前提交。提交后脚本、参数和判定冻结，只运行一次。

## 0. 来源与问题

- **来源：** 用户 2026-11-10 的问题："币种之间相关性很高，很多币跟 BTC、ETH 走势趋同，是否有价值？"以及波动率教材评估（`2026-11-10-quant-volatility-trading-book-assessment.md`）中的 H2：截面平均相关性作为组合风险状态。
- **问题：** 山寨币的截面平均相关性越高，同向持仓的组合就越接近"一个大仓"。把它加进组合波动预测，再驱动只减不加的仓位缩放，能否比只用组合自身历史波动（HAR）更能压住尾部风险？
- **性质：** 风险层规则候选。指标与方向无关，判定直接使用决策指标（尾部与超额风险），不用预测指标。这是 DVOL 仓位 S1 的教训：预测更准不等于缩放更好。

## 1. 诚实声明与现状

- **现行风控已经按相关性为 1 计算。** LLM 交易员的账户止损风险上限把每个仓位的止损风险直接相加（`trader/auto_trader_risk.go`），相当于假设所有止损同时触发，是最坏情况。另有同向净风险上限。
- 所以相关性能带来的改进只有一种：**降低"所有止损同时触发"的概率**。相关性高时提前减仓。这正是本检验的对象。若要"相关性低时放宽上限"，前提是入场有正优势，而目前没有（实盘 E[R] 为负），本次不检验放宽。
- 已知结论：
  - DVOL 仓位 S1（`2026-11-10-dvol-sizing-s1-study.md`）在 2023-01 至 2026-10 区间显示，HAR 缩放（B）在 BTC、ETH 和四币组合上，ES 与超额风险损失都优于不缩放（U）。本次以 B 为主对照。
  - 同一区间已用于 DVOL 两次 S1；TOP20 时点组合和相关性变量此前没有看过。
  - 历史上 BTC 对冲因子组合与风格中性化 S1 都失败，但那些是收益层检验，与本次的风险层问题不同。

## 3. 组合与变量（日 t 收盘时可得）

**排除项：** BTCUSDT、ETHUSDT、USDCUSDT、PAXGUSDT、XAUTUSDT，以及 `scripts/factor_mining/data_fetch.CRYPTO_EXCLUDED`。

**时点成员 S^N_t：**
- 在剩余币种中，取截至 t 已有 ≥ 60 根日线、按 20 日平均成交额（volume × vwap）排名前 N 的币。口径与 `scripts/factor_mining/panel.load_panels` 相同，同名次按代码排序。
- 只用 t 及以前的数据。

**组合日收益：**
- r^N_d = mean_{i∈S^N_{d−1}} (C_{i,d} / C_{i,d−1} − 1)，即在 d−1 收盘按成员等权建仓、每日重设。
- 成员缺 C_{i,d} 时，当日剔除该成员并计数。

**HAR 分量（年化方差）：**
- RV1_t = 365 (r^N_t)²；
- RV7_t、RV30_t 为 d = t−6..t、t−29..t 的 365 (r^N_d)² 均值。

**相关性状态：**
- ρ̄_t：S^N_t 成员中在 t−29..t 有完整 30 个日对数收益的币，两两 Pearson 相关系数的平均值；可用成员 n_t < 15 时该日剔除。
- 分散化因子 D_t = (1 + (n_t − 1) ρ̄_t) / n_t，即各成员波动相同时，等权组合方差与单币方差之比。

**目标：** Y_t = (365/7) Σ_{i=1..7} (r^N_{t+i})²。

所有回归取自然对数。任一项 ≤ 0 时该日剔除并计数。

## 4. 模型、校准与缩放

**模型：**
- B（HAR）：ln Y = a + b1 ln RV1 + b2 ln RV7 + b3 ln RV30；
- C（HAR + 相关性）：B 加 c × ln D_t。
- 描述用：T（σ̂ = √RV30）、U（k ≡ 1）。

**估计：**
- 与 DVOL S1 完全相同：OLS，扩展窗口，每月第一天 m 重估，训练样本满足 t + 7 < m，训练从 2021-01-01 开始。
- 尽量复用 `scripts/backtest/dvol_vol_forecast_study.py` 和 `dvol_sizing_study.py` 的函数。

**校准：**
- F = exp(ŷ + s²/2)，s² = Σe²/(n − p)；
- σ̂ = √F。

**缩放：**
- σ_ref,t = 从 2021-01-01 到 t（含）全部有效 √RV30 的中位数；
- k_t = min(1, σ_ref,t / σ̂_t)；
- x_t = k_t × r^N_{t+1}。

**评估日：** 2023-01-01 至 2026-10-26。B、C、T、U 都有效的共同日期。

## 5. 载体与指标

**载体：**
- 主载体 TOP20（N = 20）；
- 稳健性载体 TOP10、TOP50。每个载体用自己的成员、自己的 ρ̄ 和 D、自己的模型。

**指标**（与 DVOL 仓位 S1 相同，便于对照）：
- x̃ = x ÷ 评估期平均 k；
- **ES：** |x̃| 最大的 ⌈0.025n⌉ 个值的平均；
- **超额风险周损失：**
  - 评估日序列每 7 个切一块，丢弃不满 7 天的尾块；
  - V_b = (365/7)Σx̃²；
  - V* = U 的 V_b 中位数；
  - ℓ_b = max(0, ln(V_b/V*))²；
  - d_b = ℓ_B,b − ℓ_C,b（为正表示 C 更好），普通 t（ddof = 1）；
  - 两半按块数平分，奇数时前半取 ⌊n/2⌋。

## 6. 判定

- **R1（TOP20）：** 周损失配对 t ≥ 2.0，且前后两半 mean(d) 都 > 0。
- **R2（TOP20）：** ES_C < ES_B，且 ES_C < ES_U。
- **R3（稳健性）：** TOP10 和 TOP50 各自满足 mean(d) > 0 且 ES_C < ES_B。

| 判定 | 条件 |
|---|---|
| invalid | 第 2 节校验不过 |
| pass | R1、R2、R3 都成立 |
| weak | R1、R2 成立，R3 不成立 |
| fail | 其他情况 |

**后果：**
- **pass：** 另写接入设计与在线配对（S2）预注册。候选做法是在 LLM 交易员的账户止损风险上限上乘以按相关性预测得到的 k，只减不加；对照为现行规则。不改现行配置。
- **weak：** 记录在案，不接入。
- **fail：** 不接入，记录在案，不调参重跑。

## 9. 已知局限

- 等权 TOP20 每日重设只是 LLM 持仓的代理；实际持仓 1–5 个，多为小市值币，方向多空都有。
- 收盘到收盘的 RV1 噪声大，没有用日内数据。
- 评估期与 DVOL 两次 S1 相同，缺少 2022 年式的完整熊市；训练期为 2021–2022 年（包含 2021 年牛市和 2022 年熊市）。
- 下架币缺 t+1 收盘时直接剔除，可能略微低估下架前后的损失，剔除比例会报告。
- 多重检验：主判定只有一组设定；T、QLIKE、五分位、夏普等只作描述。
