# DVOL 对永续未来波动的增量预测：S1 预注册（2026-11-10）

## 0. 问题

来源是 `docs/research/2026-11-10-quant-volatility-trading-book-assessment.md` 的 H1。

**问题：** Deribit 的 DVOL（30 天隐含波动率指数）能否在 HAR 已实现波动模型之外，提升 BTC、ETH 永续未来 7 日已实现波动的样本外预测？

**性质：**
- 风险与仓位层的预测检验，不是交易规则，不计入任何交易线的 K，不写账本。
- 即使通过，用于仓位还需要另做一次预注册的 S1。
- 本研究只读数据，不改任何交易配置。

## 1. 数据（下载后保留，不删除）

- **DVOL 日线：** Deribit `public/get_volatility_index_data`，参数 `currency=BTC/ETH`、`resolution=1D`，行为 [t_ms, open, high, low, close]，区间从 2021-03-24 起到下载日。
  - 存放于 `data/dvol/{BTC,ETH}.json`，manifest 记录 sha256、行数和区间。
  - 只用 close：DVOL 日线 t_ms 为 UTC 00:00，close 对应当日 24:00（UTC）的指数值。
- **永续日线：** 复用 `data/carry/perp_1d/{BTCUSDT,ETHUSDT}.json`（2026-11-09 下载，manifest 已有 sha256），行为 [openTime, o, h, l, c, v]。
- **校验（任一不过，判 invalid）：**
  - 2021-03-25 至 2026-11-07 区间内，DVOL 与永续日线缺失的天数各 ≤ 1%；
  - DVOL close 的取值都在 (5, 400) 之内。

## 2. 变量（日 t 收盘时可得，单位：年化方差）

- 永续日对数收益：r_t = ln(C_t / C_{t−1})。
- Parkinson 日方差：P_t = (ln(H_t / L_t))² / (4 ln 2) × 365。
- **HAR 分量：**
  - RV1_t = P_t；
  - RV7_t = P_{t−6..t} 的均值；
  - RV30_t = P_{t−29..t} 的均值。
- **隐含方差：** IV_t = (DVOL_close_t / 100)²。
- **目标（未来 7 日已实现方差）：** Y_t = (365/7) × Σ_{i=1..7} r_{t+i}²。
- 所有回归取自然对数。Y_t 或任一自变量 ≤ 0 时，该日剔除并计数。

## 3. 模型与样本外流程

- **基线 B（HAR）：** ln Y_t = a + b1 ln RV1_t + b2 ln RV7_t + b3 ln RV30_t + e
- **候选 C（HAR + DVOL）：** 在 B 的基础上加一项 c × ln IV_t。
- **估计：**
  - OLS，扩展窗口；
  - 每月第一个交易日重新估计，用到该日为止、目标已完全实现的样本（t + 7 ≤ 估计日）。
  - 该月内各日都用这组系数预测。
- **区间：**
  - 训练从 2021-04-24 开始，前 30 天用于计算 RV30；
  - 样本外预测日为 2023-01-01 至 2026-10-31，保证目标可以完全实现；
  - 两半按样本外日数平分，奇数时前半取 ⌊n/2⌋。
- BTC、ETH 分别估计，不合并。

## 4. 指标

- **样本外 R²（对数目标）：** R²_oos = 1 − Σ(ln Y − 预测)² / Σ(ln Y − 训练窗内 ln Y 的均值)²。B、C 各算一次，并取差值 ΔR² = R²_C − R²_B。
- **配对损失差：** d_t = e_B,t² − e_C,t²。只取不重叠样本（样本外第 1 天起每 7 天取一个），t = mean(d) / (sd(d)/√n)，即普通 t。
- **辅助指标：** QLIKE 损失 L = Y/F − ln(Y/F) − 1，其中 F = exp(预测)，不做方差偏差修正。同样报告 B、C 两个模型的数值及其差值。

## 5. 判定

| 判定 | 条件 |
|---|---|
| invalid | 第 1 节数据校验不过 |
| pass | BTC 和 ETH 都满足：ΔR² ≥ 0.02；不重叠 t ≥ 2.0；样本外前后两半的 ΔR² 都 > 0 |
| weak | 不满足 pass，但两个币的全样本外 ΔR² 都 > 0，且不重叠 t 都 > 0 |
| fail | 其他情况 |

**后果：**
- **pass：** 另写预注册，检验"用含 DVOL 的波动预测做仓位缩放"在 fq_crypto 或 LLM 交易中的效果（S1）。
- **weak 或 fail：** 不接入，记录在案。

## 6. 仅描述，不参与判定

- **波动率风险溢价（VRP）：** VRP_t = IV_t − Y_t，报告均值、中位数、为正的比例，以及按年份的分布。
- **VRP 与后续表现：**
  - VRP 或 IV − RV30 的五分位，与未来 7 日永续收益和最大回撤的关系，只作描述，不作择时结论；
  - DVOL 日变化与同日永续收益的相关性（"杠杆效应"）。
- **两个敏感性模型：**
  - 只用 ln IV 单变量预测；
  - HAR 加 ln IV − ln RV30。

## 7. 已知偏差与局限

- 只有 BTC、ETH 两个标的，5 年半样本，包含 2021 年牛市、2022 年熊市和 2024 年牛市。
- DVOL 是 30 天期限的隐含波动率，目标取 7 天，期限不匹配；这是事先确定的选择，不调整。
- DVOL 的计算方法可能在样本期内被 Deribit 修订过，无法核实。
- 已实现方差用日线计算，没有用日内数据，噪声较大。
- 多重检验：主判定只有一组模型设定。敏感性模型只作描述，不得事后替换。
- 前视检查：DVOL 当日 close 与永续当日收盘同在 UTC 24:00，目标从 t+1 开始，没有重叠。
