## 1. 数据校验（全部通过）

- BTC、ETH 主检验区间共 2502 天，现货和永续日线都没有缺失，资金费结算没有缺失（各 7506 次）。
- 永续收盘价与因子面板逐日吻合，比例 100%。
- Backtrader 与算术参考逐日权益的最大相对误差为 6e-15。
- 资金费结算中有 4989 次缺少 markPrice（Binance 历史数据早期不提供），按预注册用永续当日收盘价代替。

**下载时修复的一个问题：** Binance 的 `fundingRate` 接口把 `startTime=0` 当作没传，只返回最近 500 条。第一次下载因此只拿到了 2026-05 之后的数据。改为从 2019-09-01 开始分页后，拿到了完整历史，并加了回归测试。正式运行用的是完整数据。

## 2. 最大回撤的来源：一根成交价插针

25.8% 的回撤几乎全部来自 2020-03-13（"黑色星期四"）这一天：ETH 那一半当天亏了 50.7%。

| 2020-03-13 | 最高价 |
|---|---|
| ETH 现货 | 139.68 |
| ETH 永续成交价 | **323.00** |
| ETH 永续标记价格 | 139.32 |
| ETH 指数价格 | 139.44 |

- 永续成交价出现了一根插针。按预注册"永续最高价触及击穿线"的规则，这一天被判保证金击穿：永续按 297 平仓，现货却只能按 139.6 卖出。
- 但交易所的强平依据的是**标记价格**，而标记价格当天最高只有 139.3，实际上不会触发强平。
- 所以这是预注册规则的建模缺陷，不是策略的真实风险。按预注册，判定仍以原规则为准，不做修改。

**事后对照（只作描述，不计 K、不改判定）：** 只把这一天 ETH 永续的最高价换成标记价格的最高价，其余不变。

| 项目 | 原规则 | 事后对照 |
|---|---|---|
| 年化 | 3.8% | 7.7% |
| z | 0.99 | 8.6 |
| 最大回撤 | 25.8% | 0.6% |
| 前半 / 后半年化 | 4.2% / 3.4% | 12.1% / 3.4% |
| 近一年年化 | −0.06% | −0.08% |
| 按预注册规则判定 | weak | **仍为 weak**（近一年不为正） |

即使修正这个缺陷，结论也不变：近一年没有收益。

## 5. 判断

- **机制成立，但现在不赚钱：**
  - 资金费 carry 在牛市阶段确实有可观收益；修正插针后，2020–2021 年年化 15%–25%，回撤很小。
  - 但近两年资金费水平被压缩，扣除成本后接近 0，近一年没有收益。
- **成本与接入：**
  - 要接入，需要给加密模拟盘补现货腿、处理资金划转和保证金补充，工程成本不低；
  - 而当下的收益不足以支撑这份成本。
- **以后可以重新考虑的条件（需另行预注册）：** 资金费重新长期处于高位，例如主流币 7 日年化持续高于 10%。到那时，同一规则用新的样本外数据重新做 S1。
- **方法上的教训：**
  - 用永续成交价的最高价判断强平，会被插针误伤。以后涉及强平的回测应使用标记价格（`/fapi/v1/markPriceKlines`）。
  - 这也正是网页卡片 1.5"坏 tick 过滤"提醒的问题。

## 局限

- 只用日线，没有模拟日内基差、日内强平和划转延迟。
- 32 次"保证金击穿"在真实账户里多数可以用现货浮盈补保证金来避免，因此收益偏保守。
- 标的是幸存者；事后对照是看过结果后做的，只作描述。
