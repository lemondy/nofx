# 物理类交易方法评估：动量、冷却定律、波浪与 econophysics（2026-11-11）

**结论档位：证据不足。** 没有可以直接接入 nofx 的内容，LLM 交易路径和 factor_quant 都没有。

- **资料性质。** 用户转述好友的说法：用物理学方法交易，"获利很多"，例子是动量、冷却定律、波浪理论。好友没有给出规则、代码、成交记录或业绩曲线，所以"获利很多"是未经证实的说法，本文不把它当证据。
- **怎么评。** 本文把每个物理隐喻翻译成可证伪的交易规则，再逐条对照两样东西：公开文献，以及 nofx 已经做过的研究。
- **公开证据。** 约 40 个来源里，没有一篇同时满足四个条件：物理方法、样本外、扣成本、适用于加密永续 1h–7d 或美股日线。
  - 有扎实证据的只有价格动量，而且是期货月频、未扣成本的毛收益。
  - 直接以"物理动量"或"牛顿冷却定律"为题的论文：一篇不扣成本、没有样本外，另一篇输给随机游走。
  - 研究这些方法的文献里，最强的结论是反面的：技术规则在数据挖掘校正、样本外和扣成本之后普遍失效。
- **nofx 已有覆盖。** 这些隐喻能变成的规则大部分已经测过，都没有增量：
  - 动量：美股 12-1 动量（S2 在跑），宽池扣成本后约为 0；
  - 冷却定律（均值回归）：加密 4–24h 反转存在，但被换手吃掉；
  - 波浪：三推、Fib+FVG+BOS、Wyckoff、Kell 周期，全部无效；
  - Hurst、方差比、自相关、凸性（超指数）：regime-statistics 与概率研究里全部无效。
- **真正没测过的：** 熵、LPPL、傅里叶/Hilbert 周期、成交量加权的"物理动量"。
  - 前三项的公开证据弱，或者只是已测特征的近亲，不值得单独花 K。
  - 只有"物理动量"能低成本地做成干净的单因素对照。H1 的预注册已写好：`docs/research/2026-11-11-physical-momentum-s1-prereg.md`，fq_us，K=8。H1 先验偏低，**未运行**，要等用户批准。
- **本轮范围：** 只做理解与实验方案。没有用真实数据计算任何收益或 IC，没有改任何交易配置或提示词，没有下单。

## 2. 物理隐喻 → 可证伪的交易规则

| 隐喻 | 物理含义 | 翻译成交易规则（可证伪形式） | 规则族 |
|---|---|---|---|
| 动量 p = m·v | 速度乘质量；没有外力时保持运动 | ① 价格动量：过去 N 期收益为正则做多（时间序列），或做多赢家、做空输家（截面）；② "物理动量"：用成交量、换手或 1/σ 作质量，对收益加权，Choi 2014 | 趋势/延续 |
| 加速度、力 | 速度的变化率 | 收益的二阶差分为正则顺势加仓 | 趋势/延续 |
| 动能 ½mv² | 运动的能量 | 成交量 × 收益²，约等于"放量大波动"，本质是波动和成交量特征 | 波动 |
| 牛顿冷却定律 dT/dt = −k(T − T_env) | 物体温度按指数回到环境温度 | ① 价格偏离均线 z = (p − EMA)/σ 过大时反向交易，按半衰期 ln2/k 持有（即 OU 均值回归）；② 热点（暴涨、放量、资金费高）的超额收益按指数冷却，事件后反向 | 反转/回归 |
| 波浪理论（Elliott） | 5 浪推动 + 3 浪调整，斐波那契比例 | 第 5 浪末端反向；回撤到 0.618 入场；按浪型数量确定目标 | 形态 |
| 振荡 / 谐波 | 周期运动，有固有频率 | FFT 或 Hilbert 找主周期，在周期低点买、高点卖 | 周期 |
| Hurst / 分形 | 长程相关：H > 0.5 持续，H < 0.5 反持续 | H > 0.5 用趋势策略，H < 0.5 用回归策略 | 状态切换 |
| 熵 | 无序度 | 熵低（有序、可预测）时交易，熵高时空仓；或者用熵预测波动和 VaR | 状态 / 风险 |
| 相变 / 临界减速 | 临界点前恢复变慢：自相关↑、方差↑ | 自相关和方差同时上升时降低仓位或做空 | 风险预警 |
| LPPL（对数周期幂律） | 正反馈导致超指数增长，叠加加速的对数周期振荡，在 tc 附近崩溃 | 置信指标高时减多或做空，等待崩盘 | 泡沫预警 |

这些规则落在五个族里：趋势延续、反转回归、形态、周期或状态切换、风险预警。"物理"只是名称，规则本身与传统技术分析没有区别。这正是 nofx 过去一个月研究最多的范围。

**小结：**
- 有物理名称的方法里，证据最好的是价格动量，但它不需要物理学，也不是新东西。
- "物理动量"和"冷却定律"各只有一篇直接论文：前者不扣成本、无样本外，后者输给随机游走。
- 波浪、周期、谐波没有一个严格检验是正面的。
- Econophysics 的指标对**风险**（波动、VaR、泡沫状态的描述）有弱证据，对**方向**没有证据。

## 5. 可检验的假设（按优先级）

### H1（已预注册，等待批准）：成交量加权"物理动量" vs 12-1 动量，fq_us

- **机制：**
  - 把 Choi 的 p(2) = Σ m·v / Σ m 用到 12-1 窗口：v 为日对数收益，质量 m 为当日成交量。
  - 当 m 恒为 1 时，p(2) 的排序与现行 mom12_1 完全相同。所以与基线唯一的差别是"放量日的收益权重更大"。
  - 背后的经济直觉：放量的价格变动带有信息，持续性更强；缩量的漂移更可能是噪声。文献中有"高成交量收益溢价"的说法，但方向有争议。
- **改动：** 只换信号。股票池、调仓、两腿、1/σ 加权、成本与 `mom_ls_invvol_v1` 完全相同，用 Backtrader 两腿执行。
- **数据：**
  - 主检验 D3：标普 500 宽池，2012-11 至 2026-10，已在本地，哈希冻结；
  - 方向一致性检查 D2：bStock，2021–2026；
  - 不需要下载新数据。
- **指标：** 每 20 日周期的配对差 Δ_k = r_k(候选) − r_k(基线)，做 z 检验，看前后两半，再与成交量时间平移的安慰剂比较。
- **失败条件：** 见预注册。z < 1、任一半为负、低于安慰剂的 90 分位、或 D2 均值为负，都判 fail。
- **成本：** 低。复用 `fq_us_volscale_study` 的加载和两腿执行，新增约 150 行和测试，按 CLAUDE.md 的档位交给 Codex（fq 属于"一般"档）。
- **先验：偏低。**
  - Choi 的原结果是周度**反转**，不扣成本，也没有样本外；本检验把它改造成 12-1 动量，是本文的推断，不是复现。
  - D3 上的基线本身约为 0。即使 Δ > 0，也只说明"比一个不赚钱的规则好一点"。
  - 两个臂的持仓高度重合，Δ 的效力有限。
- **可能的冲突：** fq_us K 从 7 增加到 8，后续 fq_us 检验的 strong 门槛相应提高。D3 的 mom12_1 已被看过，但成交量加权版本从未计算过。

### H2（不预注册，只记录）：LPPLS 作为加密多头的回撤预警

- 这是唯一真正新的风险层想法，但不建议现在做：
  - 超指数增长部分已被 `convexity_t` 检验过，无效；
  - 可交易性在文献中没有独立证据，tc 参数也不稳定；
  - 加密日线上的大泡沫事件很少（文献识别 BTC 2012–2018 只有 3 个大峰），统计效力不够；
  - 实现成本中等：每个币每天都要做非线性拟合。
- 如果以后要做，形式应与 regime-statistics 的 T3 一致：LPPLS 置信指标对未来 7–14 日回撤风险的增量，要在波动基线和 `last_jump` 之外。这需要另写预注册，计入 crypto_llm 或 fq_crypto 的 K。
