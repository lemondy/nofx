## 一、核心结论摘要

1. **`K=16` 预注册候选 `C1`（`fq-crypto-squeeze-cooldown-invvar-v1`）未通过 S1 筛选（`verdict = fail`）**：
   - 相对基线 `B_S20_baseline`（固定 ±20% 止损）：配对日均收益差 **`-0.783 bps/d`**（`val -0.033 bps/d`、`holdout -2.322 bps/d`），`z = -0.270`（远低于 `z_16 = 2.955`），200 次匹配随机安慰剂分位 `68.0%`。
   - **归因拆解揭示了关键反直觉机制**：
     - **`C1c_cooldown_only`（10 天同向止损冷却）是主要负贡献**（`-4.334 bps/d`, `z = -1.764`, 合并收益从 `-9.13%` 恶化至 `-28.70%`, MaxDD 从 `-31.65%` 恶化至 `-43.42%`）。在加密山寨币横截面反转/空头因子中，单币被轧空打掉止损后，10 天内往往会出现剧烈均值回归下跌；强制拉黑 10 天反而错过了止损后最具赔率的回落段，并迫使权重再分配到更拥挤/更差的次优候选币上。
     - **`C1a_invvar_only`（全状态 `1/σ²` 空头加权）** 几乎中性（`+0.018 bps/d`, `z = 0.016`）。
     - **`C1b_squeeze_guard_only`（3日涨幅≥90分位或放量≥2x 禁空过滤）** 样本不稳定（`val +1.722 bps/d`, `holdout -1.993 bps/d`, 合并 `+0.505 bps/d`, `z = 0.261`）。
   - **决策**：**不落地 `C1` 三件套（不做 10 天冷却、不做全状态 `1/σ²`、不做 `ret3/vol5` 禁空过滤）**。

2. **非-K 描述性诊断（PR #121 四开关消融）发现极高 ROI 的既有配置优化线索**：
   - 在完全相同的 NautilusTrader 1.222.0 + 8h 资金费率口径下，对 PR #121 引入的 4 个开关（`regime_tilt`、`rolling_exit`、`vol_adaptive_stop`、`drawdown_scale`）逐项做「单加（Add-One）」与「留一（Leave-One-Out）」消融后发现：
     - **`regime_tilt` 是第一大收益保护项**：留一去掉后合并收益从 `+5.40%` 暴跌至 `-16.27%`（`-21.67pp`），Sharpe 从 `+0.270` 暴跌至 `-0.490`，`holdout` Sharpe 从 `+0.571` 暴跌至 `-1.351`。
     - **`rolling_exit` 是第二大正贡献项（推翻“高换手吃掉收益”的先验担忧）**：虽然成交笔数从 5,743 增至 10,501，但额外手续费仅增加 **\$627**（\$4,750 → \$5,377），却在 `val` 与 `holdout` 两个区间**双向稳定增厚收益**（留一贡献 `+10.73pp` 收益、`+0.314` Sharpe；单加贡献 `+14.70pp` 收益、`+0.368` Sharpe）。
     - **`drawdown_scale` 有效压低尾部回撤**：留一去掉后 MaxDD 从 `-18.95%` 扩大至 `-26.28%`（`-7.33pp` 回撤保护）。
     - **`vol_adaptive_stop` 是当前线上配置中的唯一净拖累项**：
       - 单加到 `B_S20`：收益 `-9.13% → -12.91%`（`-3.78pp`），Sharpe `-0.096 → -0.199`，止损触发次数从 255 激增至 352（+97 次误止损）。
       - 从 `ALL4_live_paper` 留一关闭（`ALL4_minus_vol_adaptive`）：**合并收益翻倍（`+5.40% → +10.97%`），Sharpe 从 `+0.270 → +0.416`，Calmar 翻倍（`+0.193 → +0.389`，全场 11 组最高！），`holdout` 收益 `+5.90% → +14.75%`（Sharpe `+1.168`，MaxDD `-11.15%`，胜率 `55.43%`），且合并 MaxDD 几乎不变（`-18.95%` vs `-18.97%`），止损次数减少 105 次（380 → 275）！**
   - **机制解释**：加密山寨币 3 日换仓窗口内日内毛刺噪声大，`2.5 * vol30 * sqrt(3)` 在中低波动币种上将止损收紧至远低于 `20%`（下探 `8%`），叠加 Chandelier 追踪上移后在正常 3 日震荡中被频繁“洗出”。改回固定 `±20%` 宽保护止损同时保留 `regime_tilt + rolling_exit + drawdown_scale`，既守住尾部底线又避免了 105 次过度止损磨损。
   - **注意（合规边界）**：本消融属于非-K 诊断结果，尚未修改线上数据库 `data/data.db` 配置；建议用户审批后，关闭 `fq_crypto` 模拟盘的 `vol_adaptive_stop`（回退固定 20% 止损）并保留其余 3 个开关，或在后续做正式配对观察。

## 四、局限性与下一步

1. **局限性**：`val` + `holdout` 合计约 1.47 年，覆盖了一段 BTC 震荡上涨与山寨币剧烈分化周期；四开关消融的 `ALL4 - vol_adaptive` 收益优势虽然在 `holdout` 上高达 `+14.75%`（Sharpe `+1.168`），但其在 `val` 上略低于 `ALL4`（`-3.29%` vs `-0.48%`），因此应作为配置精简建议交由用户审批，并在模拟盘中跟踪验证。
2. **明确否决的方向（后续不再重复）**：
   - `fq_crypto` 10 天同向止损冷却（`C1c` 强烈负贡献）；
   - `fq_crypto` 全状态 `1/σ²` 空头加权（`C1a` 无增益）；
   - `fq_crypto` 基于 `ret3 ≥ P90` 或 `vol5/vol30 ≥ 2.0` 的空头轧空过滤（`C1b` 在 `holdout` 上反转失效）。
3. **下一步高 ROI 优先级**：
   - **配置建议（待用户确认）**：关闭 `fq_crypto` 模拟盘 `vol_adaptive_stop`（回退固定 20% 保护止损），保留 `regime_tilt + rolling_exit + drawdown_scale`。
   - **结构性升级（Step 3）**：在 `scripts/factor_mining/ensemble.py` 中落地 `DSR(N_eff) >= 0.95` + 月度 IC 相关 `< 0.50` 去重闸门，从源头提升 `fq_crypto` 因子池质量，同时推进 `mega_large h=7` 赛道评估。
