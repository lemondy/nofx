# 《Where Edge Actually Comes From》评估：按“谁在付钱”给 nofx 研究归类（2026-11-11）

## 结论

- **本文是知识类材料，没有策略可以直接接入。** 它与 2026-10-31 QuantJourney 研究引用的《How to Become a Quant》应属同一系列；原文第 2 部分引用了多重检验结论，但本次没有拿到第 2 部分。那次研究已经用“谁在付钱”给 50 个示例策略标注过收益来源。本次没有新增策略或参数，没有计算任何收益或 IC，不计 K。
- **把这个分类用到 nofx 已做的约 70 项研究上，规律很清楚**：
  1. 说不出付钱方的思路，包括图形、价格行为、K 线预测、自动挖掘和多特征 ML，20 余项，**0 项通过**。
  2. 有正证据的思路全部属于行为类和风险溢价类：动量延续、波动率缩放、资金费 carry 机制和 DVOL 波动预测。
  3. 四类来源中，**“结构性/被迫交易”在 nofx 从未检验过。**
- **LLM 交易路径说不出自己的付钱方。** 它读的是公开 K 线和指标，按分钟级节奏决策，没有信息优势，也没有速度优势。能说得通的来源只有行为类的趋势延续，但实盘 E[R] = −0.077R（293 笔，95% 区间 [−0.147, −0.007]，见 `2026-11-01-probability-martingale-study.md`）。这与“no one you can name → probably noise”一致。
- **建议**：
  - **P1**：把“收益来源声明”加进预注册约定，作为立项排序依据。**已采纳**（2026-11-11，已写入 `AGENTS.md`）。
  - **H2**：结构性来源里最便宜的检验是加密强平级联的被迫卖出。先做 S0 描述，并检验 LLM 做空是否经常追在强平级联之后。是否启动由用户决定。

## 2. 核心机制

| 来源 | 谁在付钱 | 为什么一直付 | 什么会侵蚀它 | 代价 |
|---|---|---|---|---|
| 风险溢价 | 想买保险、规避风险的人 | 他们需要对冲 | 风险偏好变化、承保资本增加 | 坏时期集中亏大钱，要能熬过去 |
| 行为 | 反应慢、追涨杀跌的人 | 人性稳定；利用它的过程很难受 | 资金拥挤（发表后衰减） | 动量会在暴跌后的剧烈反弹中崩溃 |
| 结构性 | 被规则强制交易的人（指数调整、赎回、降级、强平） | 约束不变，他们就必须交易 | 被提前抢跑、拥挤 | 机会少，执行要求高 |
| 信息/速度 | 慢的参与者 | 基础设施门槛 | 军备竞赛 | 资本和基础设施成本最高 |

另有两条普遍约束。一是 **edge 衰减**：公开越久，剩下的越少。二是**容量上限**：自身的冲击成本会吃掉收益。

### 3.4 信息与速度：nofx 不具备，判断正确

订单簿不平衡（11-10，毫秒级）、日内规则（Volrix / QJ 全亏）、主动买卖差（11-01）都失败了，或者时间尺度不匹配。原文提醒速度优势需要基础设施和资本，nofx 的分钟级 LLM 决策不在这个赛道上。

### 3.5 结构性：空白

搜索研究记录和 `docs/research/`，没有一项检验过“被迫交易的对手方”。唯一沾边的是资金费 carry。2026-10-18 的另类数据采集曾想接入爆仓流，但 `allForceOrders` 已下线（404），没有接成；`data/alt_data/oi/` 只有 2026-09-18 至 10-18 约 30 天的小时级 OI，之后没有继续采集。

### 3.6 衰减与容量对 nofx 的含义

- **衰减**：nofx 检验的外部材料多是公开多年的教科书规则或已发表因子。按 McLean–Pontiff，先验应该打折，这与 0 通过的结果一致。宽池美股动量 ≈ 0 也符合“公开最久、衰减最多”。
- **容量**：nofx 账户小，容量上限主要不是自身冲击，而是成本对高换手的限制，Alpha101 有 IC 却被换手吃光就是例子；另一个限制是小币流动性，fq 空头腿暴涨币的滑点和强平都没有模拟。

## 4. 可检验的假设（按优先级）

### P1（流程，不计 K，**已采纳 2026-11-11**）：预注册增加“收益来源声明”

- **机制**：先验筛选。第 3.1 节 20 余项研究全部失败，如果立项前先回答“谁在付钱”，大部分可以降级或不做，省下预注册、数据和 K 预算。
- **改动**：在 `AGENTS.md` 外部资料研究流程第 3 步和预注册模板中，要求每个假设写明四项：
  1. 付钱方（四类之一，或写“说不出”）；
  2. 他们为什么持续付钱；
  3. 什么会侵蚀它，以及公开年限；
  4. 容量和成本上限的粗估。
  
  写“说不出”的假设仍然可以做，但需在预注册中说明为什么仍值得花 K，默认排在有付钱方的假设之后。
- **失败条件**：不适用（流程改动）。可以在三个月后回看，统计有付钱方和无付钱方的假设通过率是否不同。
- **成本**：改两处文档。
- **冲突**：无。不放宽也不收紧现有统计门槛，只影响立项排序。

### H2（结构性，加密，先做 S0，是否启动由用户决定）：强平级联的被迫卖出

- **机制（我的推断，未经验证）**：价格急跌同时 OI 急降，通常意味着高杠杆多头被强平或被迫减仓。被迫卖出的一方会接受价格让步，提供流动性的一方因此得到补偿，表现为级联后数小时的部分回补。对 nofx 来说，更直接的问题在反面：LLM 交易员 70% 是做空（309/439），**如果做空经常追在强平级联之后，就是和被迫卖出的人站在同一边，替他们付了价格让步。**
- **与“动量延续”的冲突**：Kronos S1 显示顺延伸方向的交易更好，似乎与“级联后回补”矛盾。两者可以区分：前者是普通行情，后者只针对伴随 OI 骤降的被迫成交。S0 必须报告这两个子集各自的结果，不能混在一起。
- **具体做法（分两步，各自预注册）**：
  1. **S0 描述（不计 K，不做决策）**：用 data.binance.vision UM `metrics` 日文件（5 分钟 sum_open_interest）和 5m K 线，在时点 top 60 永续（含已下架币，沿用 `crypto_full` 口径）2023–2026 上定义级联事件：1 小时跌幅 ≤ −k·σ 且 OI 降幅 ≤ −m%，阈值在预注册中冻结。报告事件后 1/4/12/24 小时的收益分布，对照组是 OI 未下降的同幅度下跌。先检查数据缺口和时间戳对齐（mark price 与 OI 时点）。
  2. **S1（B 类过滤，crypto_llm K=6）**：只有 S0 显示级联后存在回补、且 nofx 做空落在级联后窗口的比例 ≥ 10% 时才做。在 439 笔冻结交易上否决“级联后 N 小时内顺向做空”，对照组是同剔除比例的随机剔除，以及窗口 z 分数代理。
- **所需数据**：data.binance.vision UM metrics 与 5m K 线需联网下载（按 CLAUDE.md 分派给 ZCode）；放在 `data/liquidation_cascade/`。
- **评价指标**：S0 是事件后收益与对照组之差及其按日聚类 SE；S1 是 ΔavgR、z 值和安慰剂分位。
- **失败条件**：S0 回补不显著，或者级联后窗口内的做空少于 10%（与宏观事件窗口 S0 同理：机制成立但实盘碰不到，就不做 S1）。
- **成本**：中等。主要工作量在下载和清洗约 60 个币 × 3 年的 5m metrics；S1 复用 Kronos S1 的冻结交易和评估器。
- **已知风险**：
  - OI 降幅不等于强平，自愿平仓也会降低 OI，只能当代理；
  - 439 笔交易已被多项研究看过；
  - 2023 年以前的 metrics 覆盖可能不完整。

### 不提的方向（附理由）

- **美股指数纳入/剔除效应**：属于典型的结构性来源，但公开数十年。据我所知已有文献报告该效应近年基本消失（未联网核对）。nofx 美股是 LLM 选股加 fq 动量，没有被动调仓的对手方。按衰减原则，先验很低。
- **低波动/BAB 解释加密因子**：在股票里，付钱的是受杠杆约束的投资者，他们为高贝塔股付溢价；加密永续杠杆不受约束，这个付钱方不存在。我的推断是：这可以解释加密低波动因子为什么只有排序 IC、多空却不赚钱（另见 3.3）。风格中性化研究（11-05）已经关闭，没有新证据，不重提。
- **资金费 carry 重启**：已有结论是等资金费长期处于高位时再评估，本文不提供新证据。
