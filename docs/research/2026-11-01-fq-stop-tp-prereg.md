# 因子量化-加密：单币止损与分批止盈的离线验证（预注册，2026-11-01）

先写本文件，后跑结果；运行后不改动。

## 问题

程序化交易员“因子量化-加密”执行 `ls_invvol_protected_v1`：每 3 天按 h=3 因子 ensemble 调仓，多空各 50% 毛敞口，单币上限 10%，按 1/σ 加权。现行保护只有空单在开仓价 ×1.5 处止损，多单没有止损。

用户 2026-11-01 要求把多空止损都改为 20%，并询问止损阈值是否合理、能否分批止盈。本研究回答：

1. 在这个组合上，不同的单币止损阈值（含 20%）相对现行配置，是否改善风险调整后收益或回撤；
2. 在 20% 止损之上，加分批止盈或移动止损是否有增量。

## 数据与执行

- 目标：`scripts/factor_mining/quant_targets.py` 里 `_historical_targets` 的 protected 规则重放。冻结当前 crypto h=3 ensemble 的成分、表达式和方向，不重选、不调参。
- 区间：
  - val：2025-05-04 至 2026-04-30。成分选自这一段，有选择偏差，只看方向是否一致。
  - forward：2026-05-04 至面板末尾。此前的 ensemble 前向研究读过这一段，不是严格样本外。
  - 判定以 forward 为主，val 只用于方向一致性。
- 执行：Backtrader，复用 `scripts/backtest/quantjourney.py` 的 `run_weights`，扩展单币止损/止盈订单。手续费 0.05%，滑点 0.03%，计入资金费。
- K 线：日线（open/high/low/close）。止损和止盈按触发价成交；开盘跳空越过触发价时，按开盘价成交。同一根 K 线内止损和止盈都可能触发时，按先止损处理（保守）。
- 触发后：该币该方向保持减仓或空仓，直到下一次目标变化（下一次调仓）再按目标恢复，与实盘一致。
- 止损价和止盈价都以持仓均价为基准。调仓加仓后均价变化，重新挂单。

## 变体（共 11 个，计入试验次数 K）

基线 B0 为现行配置：空单 50% 止损，多单无止损。

止损变体（多空同时设置，除非另注）：

| id | 规则 |
|---|---|
| S0 | 无止损 |
| B0 | 空 50%，多无（现行基线） |
| S30 | 多空 30% |
| S20 | 多空 20%（用户要求） |
| S15 | 多空 15% |
| S10 | 多空 10% |
| SV | 波动缩放：k=2.5 × 30 日日收益标准差 × √3，夹在 [5%, 50%] |

止盈变体（都叠加在 S20 之上）：

| id | 规则 |
|---|---|
| T1 | 有利方向 +10% 时平一半，余仓到下次调仓 |
| T2 | +10% 平 1/3，+20% 再平 1/3，余仓到下次调仓 |
| T3 | 移动止损：有利方向 +10% 后启动，从持仓期内最优价回撤 10% 平仓 |
| T4 | +15% 平一半，余仓止损上移到保本 |

## 指标

总收益、年化、日收益 Sharpe（简单收益）、最大回撤、最差 3 日收益、止损/止盈触发次数、换手与成本。

对每个变体与 B0、S20 的日收益差做块自助法：块长 5 天，2000 次，种子 20261101。报告 Sharpe 差和 P(差 > 0)。

## 判定规则（事先固定）

- **“20% 明显变差”的警示**：若 forward 中 S20 相对 B0 的 Sharpe 差 < 0 且 P(差 < 0) ≥ 0.90，并且 val 中方向相同，则向用户报告“20% 止损在本组合上有害”。用户已明确要求 20%，本研究不推翻用户选择，只给出证据。
- **改用其他止损的建议**：某止损变体须同时满足以下条件，才建议替代 S20：
  - forward 中相对 S20 的 Sharpe 差 > 0 且 P ≥ 0.90；
  - 最大回撤不劣于 S20；
  - val 中方向相同。
- **建议接入止盈**：某止盈变体须同时满足以下条件，才建议接入实盘：
  - forward 中相对 S20 的 Sharpe 差 > 0 且 P ≥ 0.90；
  - 净收益不低于 S20；
  - val 中方向相同。
- 不满足上述条件的，结论为“证据不足，不改”。

## 局限

- 只有日线，盘中路径未知，同根触发按先止损处理。
- forward 约 180 天、约 60 次调仓，统计功效有限。
- 币池是因子挖掘的 100 币面板，有幸存者偏差。
