## 0. 定位

- **阶段：** 增量评估 S2，track `crypto_llm`，类型 C（执行层），配对 id `limit-band-entry-c1`。

## 2. 样本与数据

- **样本：** 候选交易员在 [started_at, 判定时刻) 内**入场并已平仓**的 `trader_positions`，要求 `ai_managed=1`、`initial_stop_loss>0`。
- **匹配：** 按 `entry_order_id` 与 `entry_band_events.order_id`（限价成交）或 `fallback_order_id`（转市价）关联到 band 事件。
- **无持仓的事件**（`invalidated`、`ai_cancelled`）不进入主统计，只计数，计入第 4 节的“剔除比例”。
  - 理由：invalidated 多数是止损已被越过，市价臂在这些交易上大概率亏损，剔除它们对候选不利，是保守处理。
  - `duplicate_ignored` 不是独立交易，只计数。
- **`stop_guard` 与 `tick_unavailable`：** 这些交易实际是市价入场，Δ = 0，计入样本。
- **执行缺陷：** 有持仓但没有任何 band 事件、或有成交事件但没有持仓，记为执行缺陷，见第 4 节 harm_stop。

## 3. 统计量

**记号：**

| 符号 | 含义 |
|---|---|
| s | 方向，多 +1、空 −1 |
| P_ref | 下单时的参考价（`entry_band_events.ref_price`） |
| SL | 初始止损 |
| P_c、f_c | 候选的实际入场均价与费率：限价成交为挂单 2bp；转市价为吃单 5bp，实际成交价已含模拟盘滑点 |
| X | 实际出场均价 |

**定义：**

- 反事实市价入场价 E_m = P_ref·(1 + s·0.0003)，吃单费 5bp。
- R0 = |E_m − SL|。
- 候选：C = [s·(X − P_c) − f_c·P_c − 0.0005·X] / R0
- 反事实：B = [s·(X − E_m) − 0.0005·E_m − 0.0005·X] / R0
- Δ = C − B。
- 部分成交按单位数量计算，与 S1 相同。

**主统计量：** Δ 的均值，**按入场 UTC 日聚类**求 SE。30 天只有 4–5 个周簇，周聚类 SE 不稳定，所以按周聚类只作报告。

**两半：** 按入场时间排序，切成笔数相等的前后两半。

**成交率（穿价 2bp 口径）：** filled /（filled + fallback + partial）。

## 4. 判定

| 结论 | 条件 |
|---|---|
| invalid | 两臂配置 diff 不符合第 1 节；或候选策略被 UI 修改；或 `entry_band_events` 缺失超过 5% |
| harm_stop | 运行 ≥ 14 天且 Δ < −2·SE；**或者**任一执行缺陷：未保护持仓超过一个扫描周期、同币同向重复持仓、有持仓无事件，或有成交无持仓 |
| promote | 满足以下全部 |
| short_only | 满足 promote 的全部条件，但多头 Δ 的 z ≤ −2：只建议对空头启用 |
| extend | 达到最短运行但不满足 promote，且 SE > 0.01：延长 14 天，最多一次 |
| reject | 其余 |

**promote 的条件：**

1. 运行 ≥ 30 天，且候选的主统计样本 ≥ 100 笔；
2. Δ − 1.645·SE > 0；
3. 前后两半 Δ 都 > 0；
4. 剔除比例（invalidated + ai_cancelled）/（全部 band 事件 − duplicate_ignored）≤ 10%；
5. 成交率 ≥ 70%。

**最长运行：** 44 天（30 天加一次延长）。到期仍不满足 promote，即判 reject。

**promote 之后：** 由用户决定是否用于实盘。实盘要先小额，并且需要另行批准。

## 5. 辅助与仅描述项（不参与判定）

- **对照臂 S1 前向复现：** 对照交易员同期的市价交易，用 S1 冻结脚本的反事实规则（θ\*、严格穿价、30 分钟转市价）计算 Δ。时间窗和交易员 id 在报告脚本中固定，作为方向一致性检查。
- 两臂整体 avgR 差，以及按周聚类的配对差（功效不足，只报告）。
- 两臂的开仓数比；候选每笔挂单期间，LLM 发出重复开仓和平仓指令的次数。
- θ\*、s_G、γ 的分布；`theta_fallback_phi` 的比例。
- 成交率的三种口径：触价、穿价 2bp、穿价 5bp。需要另外拉取挂单期间的 1m K 线计算。
- 按方向、按周分组的 Δ。

## 6. 局限（预先承认）

- 模拟盘没有队列。穿价 2bp 只是近似，真实成交率可能更低。
- 反事实市价臂用的是 P_ref 加固定 3bp 滑点，不是真实成交。
- 挂单期间 LLM 看到的是挂单而不是持仓，后续决策可能不同；这部分效应在主统计里无法分离，只在第 5 节描述。
- 判定期大约是 2026-11 下旬到 12 月，仍然是一段单一行情。
