## 含义

1. **LLM 做多的币大多落在因子判定的弱币一侧。** 51% 的做多落在全币池分位最低 20%，与“LLM 偏好高波动小币”一致。
2. **LLM 在这些币上的做多不比在其他币上差，反而更好。**
   - 因子在截面上识别的是“3 日内相对全市场偏弱”，而 LLM 做的是带止损、按小时管理的方向性交易。
   - 两者的预测对象不同：高波动币的 3 日截面收益差，并不意味着 LLM 带止损的短线做多在这些币上更亏。
3. **因子作为 LLM 做多的否决器无效。**
   - 加上 fq_crypto 的两次 S1（宽因子池、PIT60 + BTC 对冲）和 11-01 的 ensemble 前向研究，这批截面因子在加密市场的三种用法都没有通过：独立多空、对冲多头、LLM 过滤器。
   - 剩下仍在跑的只有 A 类线上配对（因子 ensemble 参考字段，由大模型自行权衡）。
4. **局限：**
   - 样本只有 138 笔、7 周的被否决集，而且只覆盖 2026-09-17 → 10-31。
   - 区间内 LLM 交易员的配置变更了约 35 次。
   - 不过结果方向与假设相反，样本再多也难以翻转为 `screen_pass`。
