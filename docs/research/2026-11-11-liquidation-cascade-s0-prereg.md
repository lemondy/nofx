# 加密强平级联 S0：价格急跌 + OI 骤降之后的回补（预注册，2026-11-11）

- **来源：** `docs/research/2026-11-11-edge-sources-assessment.md` 的 H2。
- **性质：** S0 只描述机制，**不计 K**，不写账本，不改任何交易配置、提示词或因子挖掘。
- **提交顺序：** 本文件在下载任何数据、计算任何收益之前提交。跑完之后不改参数；口径错误只能另写更正说明并如实披露。

## 收益来源声明

| 项 | 内容 |
|---|---|
| 付钱方 | **结构性（被迫交易）。** 高杠杆多头被强平，或者因为保证金不足而被迫减仓。他们必须立即卖出，不能选择价格 |
| 为什么持续 | 永续合约杠杆高，强平由交易所引擎按标记价格自动执行，不考虑成交价，所以每次急跌都会产生一批不看价格的卖单 |
| 什么会侵蚀它 | 做市商和套利者提前挂单接盘；交易所的强平机制（ADL、保险基金、分批强平）改进；该现象在加密圈公开已久（“接针”），回补幅度可能已被压缩 |
| 容量和成本 | 事件持续以小时计，单次深度有限；nofx 的仓位很小，本身不是约束。往返成本约 0.16%（0.05%/边 + 0.03% 滑点，两边），回补幅度需明显大于它才有经济意义 |

## 要回答的问题

1. **A（机制）：** 1 小时内价格急跌并且 OI 骤降之后，未来数小时是否比“急跌但 OI 没有下降”的情况回补更多？
2. **B（是否触及 nofx）：** LLM 交易员的做空入场中，有多少落在级联之后 4 小时内？如果很少，即使机制成立，也不值得做 S1。

S0 不回答 LLM 交易会不会因此改善，那是 S1 的问题。S1 需要另写预注册，并让 crypto_llm 的 K 加 1。

### 数据检查（运行前必须通过）

- metrics：每个（币，日）应有 288 行。不足 280 行的日子，当天的 OI 记为缺失。`sum_open_interest` ≤ 0 的行也记为缺失。
- K 线：5m 不得有重复，OHLC 必须合法。把 5m 聚合成日线，与 `crypto_full/daily` 比对收盘价，相对误差 > 0.5% 的（币，日）占比要 < 1%，否则停下排查。
- 报告每个币的 metrics 覆盖率；下载 404 的（币，日）直接列出，不补造。

## 定义

时间网格是每个 UTC 整点 t。

- `close_t`：结束于 t 的那根 5m K 线的收盘价。
- `r_1h = ln(close_t / close_{t−1h})`。
- `OI_t`：`create_time == t` 的 metrics 行。
- `dOI_1h = ln(OI_t / OI_{t−1h})`，任一端缺失就跳过该整点。
- `σ`：t−1h 之前（含 t−1h）168 个整点 1h 对数收益的标准差，至少需要 150 个有效值。当前这一小时不参与计算。

事件（只看整点，且 r_1h ≤ −k·σ）：

| 类别 | 条件 | 含义 |
|---|---|---|
| **C 级联** | dOI_1h ≤ −m | 急跌并且杠杆仓位大幅减少（被迫平仓的代理） |
| **D 对照** | dOI_1h > −1% | 急跌但 OI 没有下降（不是去杠杆引起的下跌） |
| 中间 | −m < dOI_1h ≤ −1% | 不归入任何一类 |

**主参数（冻结）：** k = 3，m = 5%（dOI_1h ≤ ln(0.95)）。

**去重：** 同一个币、同一类别，24 小时内只保留第一个事件。

**入场与前向收益：**

- 入场价取开始于 t+5m 的那根 5m K 线的开盘价。跳过一根，是为了容忍 OI 快照与 K 线之间最多 5 分钟的对齐误差。
- 前向收益 `R_H` = ln(结束于 t+5m+H 的 K 线收盘价 / 入场价)，H ∈ {1, 4, 12, 24} 小时。
- 同时计算扣除 BTC 后的版本：R_H − 同窗口 BTCUSDT 的 R_H。BTC 本身只报原始收益。
- 前向窗口内 K 线缺失时，丢弃该事件并计数。
- 该币当月不在时点 top 60 内的整点不计入。

## 主指标与判定

- **主指标：** Δ = mean(R_4h | C) − mean(R_4h | D)，原始收益。
- **SE：** 对 R_4h 回归常数项与 C 指示变量，按事件所在 UTC 日期聚类（CR1）。
- **机制成立：** 以下四条全部满足才算成立。
  1. N_C ≥ 100 且 N_D ≥ 100；
  2. Δ > 0 且聚类 t ≥ 2.0；
  3. mean(R_4h | C) > 0；
  4. H1、H2 两半的 Δ 都 > 0。
- 任何一条不满足，结论为“机制不成立”或“样本不足”（条件 1 不满足时），H2 到此结束，不做 S1。

## B：LLM 交易与级联的重合

- 用同样的定义和主参数，在 B 时间范围内对 115 个交易币计算 C 事件，不受 top 60 限制，也不去重。
- 一笔交易的 `entry_time` 落在某个 C 事件的 (t, t+4h] 内（同一个币），就记为“级联后入场”。
- **报告：**
  - 做空与做多各自的级联后入场笔数和占比；
  - 缺少 OI 数据的交易笔数。
- **S1 资格：** A 的机制成立，并且做空中“级联后入场”占比 ≥ 10%（309 笔做空中至少 31 笔）。
- B 只计数，**不按是否级联后入场拆分任何 R 或盈亏**，以免提前看到 S1 的结果。

## 只描述、不参与判定

- **敏感性网格：** k ∈ {2.5, 3, 4} × m ∈ {3%, 5%, 8%}，报告每格的 N_C、Δ_4h 和 t。
- **其他时间尺度：** H = 1/12/24 小时的 Δ，以及扣除 BTC 后的 Δ。
- **全部急跌：** 不区分 OI，所有 r_1h ≤ −3σ 事件的 mean R_4h，用来对照 Kronos S1 中“顺延伸方向更好”的结论。
- **无条件基准：** 同一币池全部整点的 mean R_4h，作为漂移参照。
- **按 BTC 和山寨币分组：** BTCUSDT、ETHUSDT 与其余币分开报告 Δ_4h。
- **与成本对比：** mean(R_4h | C) 与往返成本 0.16% 的对比。

## 已知偏差与局限

- **OI 降幅 ≠ 强平：** 自愿止盈、止损也会降低 OI，所以这里只是被迫平仓的代理。交易所的强平明细（`allForceOrders`）已下线，无法直接验证。
- **成交价与标记价：** 强平按标记价格触发；本研究的事件和收益都用成交价 K 线。插针造成的急跌会进入 C 和 D 两类。
- **OI 快照时点：** metrics 的 `create_time` 是否严格等于快照时刻，官方没有说明，所以入场多跳过一根 5m K 线。
- **样本已被看过：** 2023–2026 的加密行情已被多项研究使用，但没有一项研究过 OI 变化与急跌的组合。
- **多重检验：** 主参数和主指标唯一，敏感性网格只作描述。
- **幸存者偏差：** 币池含已下架币。但下架币在 data.binance.vision 上的 metrics 可能不全，覆盖率会单独报告。
- **事件相关：** 同一天的大跌会让许多币同时触发，所以 SE 按日聚类。
