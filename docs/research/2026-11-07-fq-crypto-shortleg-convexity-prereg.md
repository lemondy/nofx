- **性质：** 只做描述，**不计 K**，不写账本，不改任何交易配置。
- **提交时点：** 本文档在计算任何分解数字之前提交；跑完之后不修改其中的定义和判定阈值。

## 1. 要回答的问题

fq_crypto 的问题是“秩 IC 很高，多空却亏钱”，见 `fq-crypto-ml-multifeature`、`pit60-btchedge`。本研究要回答：这个背离有多少可以用凸性项解释？

- **机制（推断）：**
  - 秩 IC 对单调变换不变，所以截面 Spearman(score, R) 与 Spearman(score, ln(1+R)) 完全相同，它看不到凸性。
  - 空头腿按固定份额持有，每期价格盈亏是 −R，其中 R 是持有期的算术收益。
  - 恒等式：−R = −l − (R − l)，其中 l = ln(1 + R)，并且 R − l ≥ 0。第二项 −(R − l) 永远是空头的成本，波动越高越大，期望约为 σ²T/2 + μ²T²/2。
  - 高波动币集中在空头腿，所以即使对数收益（中位数）意义上的排序是对的，空头腿也可能亏钱。

## 3. 定义

对每个信号期 p 和腿内的每个币 i：

- **持有期收益：** R_i = open[exit] / open[entry] − 1，l_i = ln(1 + R_i)，凸性项 c_i = R_i − l_i ≥ 0。
- **资金费：** 按 `vectorized_replica` 的 `holding_funding` 口径（8h 费率 × 3 计日，进场日计、出场日不计），空头收到正费率。腿内取等权平均。
- **腿级分量**（每单位腿名义，腿内等权平均）：
  - 空头腿：价格 P_S = −mean(R)，对数部分 L_S = −mean(l)，凸性 C_S = −mean(c)，满足 P_S = L_S + C_S；资金费记为 F_S。
  - 多头腿：P_L = mean(R) = L_L + C_L，其中 C_L = +mean(c)；资金费记为 F_L。
- **汇总：** 各分量对期数求算术和，按分段报告。另外报告复利后的腿收益，用于和 `ml_multifeature` 报告中的分腿回测核对。
- **核对：** 用这些分量重建的多空总收益（加上 8bp × 换手）必须与 `vectorized_replica(panels, score, start, end, 3)` 的 `main_total_return` 一致，否则先修实现。允许误差为日收益 1e-9；若复利口径造成不可避免的差异，则核对逐期收益，并说明原因。

## 4. 主指标与判定（只描述，不计 K）

主指标是空头腿凸性占比：ρ = C_S / P_S，在验证段加前向段上计算，只在 P_S < 0（空头腿价格亏损）时有定义。

| 档位 | 条件 |
|---|---|
| **机制成立（强）** | P_S < 0，ρ ≥ 1/3，并且 L_S ≥ 0：对数意义上空头排序是对的，亏损全部来自凸性 |
| **机制部分成立** | P_S < 0，并且 1/3 ≤ ρ，但 L_S < 0 |
| **机制不成立** | P_S < 0 且 ρ < 1/3；或者 P_S ≥ 0（空头腿价格不亏，凸性不是主要问题） |

B 和 R 分别判定。B 是主结论；训练段只描述。

## 5. 描述性输出（不参与判定）

1. **分段分量表：** B 与 R 的 P、L、C、F 两腿各一份，并给出净凸性 0.5·(C_L + C_S)。
2. **IC 口径对比**（每个信号日一个截面，取日均值和 t 值）：
   - Spearman(score, R)，数值上等于 Spearman(score, l)；
   - Pearson(秩化 score, R)；
   - Pearson(秩化 score, l)；
   - 前后五分位的 mean R 差与 mean l 差。
3. **按事前波动分组：** 信号日按 30 日收盘对数收益标准差 σ̂（只用 t 及以前的数据）分成五组。每组报告：
   - mean R、mean l、mean c；
   - 预测凸性 σ̂² · T / 2，其中 T 为实际持有天数；
   - 资金费；
   - 落入空头腿的比例。
   另外在全部币期上，做 c 对 σ̂²T/2 的回归，报告斜率和 R²。
4. **尾部集中度：** 空头腿中 R > 30% 的币期对 C_S 和 P_S 的贡献占比。
5. **背离对照：** 对数意义下的五分位多空 −mean(l_S) + mean(l_L) 与算术意义下的多空，是否同号。

## 6. 已知偏差与局限

- **数据已看过：** 验证段和前向段已被多项研究看过，本研究只解释机制，不构成样本外证据。
- **只是会计分解：** 恒等式本身不证明因果；凸性项的大小部分由已实现的走势决定。所以第 5 节第 3 项要用事前 σ̂ 检验它是否可以预期。
- **幸存者偏差：** 币池是快照当时的成员，存在幸存者偏差（`crypto-universe-expansion`）。
- **不提出任何交易改动。** 如果机制成立，后续只修正研究口径：加密因子的准入与评估改看算术收益（或分腿盈亏），不只看秩 IC。任何交易层面的改动都要另立假设，并让 K 加 1。
